## Suspected typos / inconsistencies in the paper (all transcribed as printed)

1. **172.u1 ($\gamma_{u,1}$), p.107 / pdf 113: $\beta/g_{z}$ vs $g_{z}/\beta$.** Printed
   $\gamma_{u,1} = [\beta/g_{z} - (1-\delta+\tau^{K}\delta)](1-\tau^{K})^{-1}$, the same as in (115)
   and the C.1 restriction on p.97 / pdf 103 (other chunk). But the C.1 expression for Q on that page,
   $Q = [(1-\tau^{K}) r_{K} + \tau^{K}\delta p_{I}]/[g_{z}/\beta - (1-\delta)]$, together with (114) $p_{I}=Q$,
   gives $[g_{z}/\beta - (1-\delta+\tau^{K}\delta)] p_{I} = (1-\tau^{K}) r_{K}$, i.e. $g_{z}/\beta$.
   Numerically this matters: with Table 1 values ($\beta=0.995$, $g_{z}=1.0025$, $\delta=0.02$, $\tau^{K}=0.5$),
   the printed form gives $\gamma_{u,1}\approx 0.005$ and $g_{z}/\beta$ gives $\approx 0.035$. Implementers should check which
   form the original code uses.
2. **(200), p.110 / pdf 116: exponent $-\mu_{G}$.** Printed $im^{X} = (1-\nu_{X})(p_{IM}/p_{DX})^{-\mu_{G}} q^{X}$
   (the same as (131) in C.1). By analogy with (195)–(197), (127) and (199), the export-sector elasticity $-\mu_{X}$
   would be expected. It has no effect when $p_{IM}=p_{DX}$ (the paper's calibration sets both to 1), but
   matters for linearization or for other calibrations.
3. **(167), p.106 / pdf 112: lowercase $p_{x}$.** The export price is printed $p_{x}$ (lowercase x, as in (136)),
   but $p_{X}$ in 157.u1, 167.i3, 178.u1, (204), (205), (209). Read as the same variable.
4. **157.u1 (list of the 48 unknowns), p.104 / pdf 110:** $p_{DX}$ is printed twice (line 1 after $p_{G}$, and
   line 2 before $R$). Total imports $im$, solved in (201) and used in 178.u1/(202), is not listed. With the
   duplicate removed the list has 47 distinct variables, so the second $p_{DX}$ is probably meant to be $im$.
5. **157.u2 (parameter list), p.104 / pdf 110:** the elasticities are printed with superscripts
   ($\mu^{C},\mu^{I},\mu^{G},\mu^{X}$), but with subscripts ($\mu_{C}$, …) in (159.u1)–(166) and (192)–(200). The
   export competitors' price is $p_{X}^{C}$ here but $p_{X}^{c,*}$ in (205) (and in (137)). The VAT share
   $w_{\tau^{C}}$ (in 179.u1, (180), (207), (210), (211)) is not in the list. The list includes $\varphi^{*}$
   and $\omega^{*}$ as well as $p_{OIL}^{*}$, which is then pinned down by the calibration condition 167.u1.
6. **197.i1, p.110 / pdf 116:** the aggregation identity is printed with subscripts, $h = h_{C} + h_{I} + h_{G} + h_{X}$
   (and the prose says "solve for $h_{X}$"), while (192)–(199) use superscripts $h^{C}, h^{I}, h^{G}, h^{X}$. The
   prose before (200) likewise writes "$im_{X}$" for $im^{X}$. Read as notation slips, not different variables.
7. **Running head on pdf 117 / printed 111** reads "APPENDIX D THE LOG-LINEARIZED MODEL", even though the
   page starts with C.2.7's continuation ((207)–(211)); this is typographical only.
